- Engine: the version reads 9.7.1-BeyondEngine, where it read 9.7.1-OXT, in `the version`, the About box and `-v`; the long version ends "(BeyondEngine)", and the web engine's files, the Linux window class, the server's home folder and the Community licence file take the new name. 9.7.1 and build 25923 are unchanged, so a script that takes the part before the "-" (`set the itemDelimiter to "-"`) or reads `the buildNumber` gets what it did; one that looks for "OXT" in the version no longer finds it (tperry2x, openxtalk.org p=25816) (#293)
- Object menu: Copy Graphics as SVG Paths also puts the SVG on the clipboard in Illustrator's formats (com.adobe.illustrator.svg, com.adobe.illustrator.svgm and com.adobe.svg), so it pastes as vector paths into Illustrator or VectorCraft; the plain text is as before (OpenXTalkPaul, openxtalk.org p=25820). The IDE tour reads each one back (#293)
- Inspector: a scrollbar's Orientation can be set, Horizontal or Vertical, which swaps its width and height about its centre; it was read only, and a scrollbar could only be turned round by dragging it (TerryL, openxtalk.org p=25821). The IDE tour sets it as the Inspector does and reads it back (#293)
- Web: on a page that follows a browser set to dark, a check box with no colour of its own draws a dark box with a white tick. Its box was white there, so an unticked one looked ticked; light pages are as before. The web check reads both in a dark browser (#293)
- macOS 11 and later: a standard button taller than 30 points is drawn its whole height, with the Mac's rounded bezel; the bezel stayed 21 points high in its middle (Skids, openxtalk.org p=25824). Buttons of the usual heights are as before, and the IDE tour checks a tall one on every platform (#293)
- CI: the standalone check lets a runtime that a package takes from the runtimes asset report the version the asset's PROVENANCE file records for it (the 32-bit Windows runtime of oxt-runtimes-0.2.7-rc.6.11, built before the rename, still read 9.7.1-OXT and failed the Windows build); any other version still fails, and the package's own runtime must read the engine's. "Tag a release" counts a change to the `version` file as engine source, so it refuses to tag until the runtimes asset is rebuilt after one (#293)
