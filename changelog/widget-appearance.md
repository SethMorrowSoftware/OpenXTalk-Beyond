- Widgets: a header bar, navigation bar, segmented control, switch button or tree view whose colours nobody set by hand follows light and dark. The IDE gives a new one its light defaults (244,244,244 behind its labels, with dark labels and a grey border) as colours of its own, so it stayed light on a dark card; in the dark appearance, on a dark card, a colour that is still its light default is now drawn in a dark one (64,64,64 behind light labels). A colour set to anything else is drawn as set, the properties read what they did, and the light appearance, and Linux unless the useDesktopAppearance is true, look as before. A colour set by hand to exactly the light default is drawn in the dark one too. Widgets get the engine handler MCWidgetGetMyPaintForAppearance for this (bwmilby, openxtalk.org p=25665, p=25680; seth's choice 2A) (#PR)
