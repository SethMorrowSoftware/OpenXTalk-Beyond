- HTML5 standalones: `go stack URL` (also `go to stack URL`, a card of one, and a script-only stack) is now checked in the web engine on every build. It opens a stack from the page's own site, and from another site whose server sends an `Access-Control-Allow-Origin` header, as on the desktop. From a site without that header the browser refuses the download and `the result` is "Request failed"; nothing a script sees changes. The Deploying guide now says so (OpenXTalkPaul, openxtalk.org p=25362) (#PR)
- CI: the web check also holds that a page's Splash image stays up until the engine has drawn the stack. 0.2.8-dp.1's engine draws it first, by about 10 ms, and by about 450 ms with the processor slowed 20 times, so no empty page shows between the two (#PR)
