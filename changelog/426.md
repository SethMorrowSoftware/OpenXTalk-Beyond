- Standalone Settings, Android card: an "OXT-Beyond engine (preview)" box under the device capabilities, which builds the stack with OXT-Beyond's own Android engine instead of LiveCode 9.6.3's (the "android,engine" setting, beyond when ticked and empty when not, which only a script could set until now). It can be ticked once an architecture is; a stack that never ticks it is built with the 9.6.3 engine, as before (#426)
- IDE tour: on the Android card, the OXT-Beyond engine box is under the device table and in line with the permissions' boxes, enabled with the Android settings, ticked exactly when the stack's engine is beyond, a click on it stores beyond or empty and nothing else, and the check boxes, radio buttons and menus under the build targets' group, grown to hold the box, still get their clicks (#426)
