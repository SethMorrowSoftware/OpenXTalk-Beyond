- xTalk Assistant: a Context length setting for a model on your own computer. OpenAI's API, which LM Studio, Ollama and the other local servers speak, has no way to say how much context a request needs, so a model loaded with LM Studio's default (4096 or 8192 tokens) refused the assistant's guide. With a context length set, LM Studio 0.4 or later is asked before each question whether the model is loaded with that much, and loads it with that much when it is not (at most what the model takes; a model loaded with more is left as it is). Empty, the default, asks nothing more than before, and online services are never asked. The setting takes the place of the note under the model, whose words are now Get Models' tooltip (#383)
- Tests: the context a local model is loaded with, through a server of the test's own that answers as LM Studio does: nothing more asked without the setting, a model loaded with less reloaded, one loaded with enough left alone, a server without LM Studio's list left alone, a load that fails said in the error; and the setting kept, checked and shown again in the Settings (#383)
