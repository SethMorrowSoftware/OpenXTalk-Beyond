- CI: the Android script tests no longer count against an engine what the test bench lacked. An Android app has no shell() (it always fails there), so the test library's "shell" requirement is false on Android as in a browser and TestRunStack skips there; the tests' standalone allows plain http, which Android 9 and later otherwise refuses before a request is sent (the tests that serve HTTP from the app on 127.0.0.1), and includes the security library ("SSL & Encryption"), without which randomBytes and encrypt threw error 720; TestProcessor knows the four architectures an Android build has (arm, arm64, x86, x86_64); and TestPeerAddress, whose result follows the network, is marked as failing only sometimes. The baselines lose the 50 entries (LiveCode 9.6.3's engine) and 41 (OXT-Beyond's) that pass with that, and the job's log now says of each failure left in a baseline the first line it gave, so that a baseline's comment can be read against the run without its artifact.
