- HyperCard import: the HyperCard Library does what more of the externals the corpus's stacks call did, where their stand-ins gave empty or did nothing: Switch (14 stacks) turns items into lines and lines into items, FindInField (9) gives where a string is as "char,line,word,item", FolderPath (8) and FullSFPack (8) show the folder, open, save and several-files dialogs, SubLaunch (8) opens an application and gives 0 or -43, ClipInfo (7) gives the clipboard's types and sizes, GetBootVol (6) gives HyperCard's disk, ChangeCurs (5) sets the cursor, IsFinderLocked (6) is false for a file that is there, and Resources (13) lists the fonts, the stack's sounds or the named resources of the stack's resource fork. What a script can see: these calls give those values where they gave empty before. This is a deliberate change, chosen by the maintainer: Switch(5), for one, now gives 5 as the original XFCN did, where the old stand-in gave empty (#543)
- HyperCard import: Harry Chesley's MacTCP externals (14 stacks: HyperFTP, HyperFinger, news readers) work on this engine's sockets: TCPNameToAddr, TCPActiveOpen, TCPSend, TCPRecvUpTo, TCPRecvChars, TCPCharsAvailable, TCPState, TCPClose and TCPRelease. TCPPassiveOpen, which would listen for a host's connection, gives a failure the stacks show, as one the external gave (#543)
