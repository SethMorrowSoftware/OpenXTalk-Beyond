- xTalk Suite: midixt built in, as `org.openxtalk.library.midi`: realtime MIDI through RtMidi, the computer's MIDI ports listed, opened and sent to, and what arrives read by polling, with its timing (virtual ports on macOS and Linux). It is the MIDI part of ShowControl under the same id and handlers, so its stacks keep working, and a copy of ShowControl's extension that a user installed still loads in place of the built-in one. The libraries are the xTalk Suite's 75d0713; on Linux they need ALSA's library (`libasound.so.2`), and the 32-bit one glibc 2.38. There are none for Android (#630)
- Web engines: midixt is linked into the web IDE's engine and every HTML5 standalone's, over the browser's Web MIDI: the visitor is asked once, with SysEx, at the first call that lists or opens a port, and a virtual port is refused, since Web MIDI cannot make one (#630)
- Tests: the web IDE's xTalk check drives midixt through a stand-in for the browser's Web MIDI with a loop cable (#630)
