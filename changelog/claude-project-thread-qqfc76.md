- xTalk Suite: xlsxt is built in: org.openxtalk.library.xlsxt writes Excel .xlsx workbooks (text, numbers, formulas, dates, links, notes, a whole table in one call, fonts, colours, borders, number formats, merged cells, frozen panes, filters, drop-down lists, pictures, charts and page setup) and reads them back, values, dates, formulas and number formats, from files other programs wrote; no existing handler changes
- Web: the web engine links xlsxt, so the web IDE, an HTML5 standalone that includes the extension and the Stack Player write and read .xlsx files in the page's own file system; every such engine's `.wasm` is larger
- CI: the web IDE's xTalk Suite check writes a workbook with a table, a formula, a date and a chart in the browser and reads it back, and a test holds the six places that name a web-linked member to each other
