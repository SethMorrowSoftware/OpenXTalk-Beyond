- Arrays: LiveCode 11's kinds of array. A literal `[...]` is a sequence and `{...}` a dictionary, a List from LCB comes back as a sequence, and new checks read the kind: `is a sequence`, `is a dictionary`, `is a numeric sequence`, `is strictly a sequence`, `is strictly a dictionary` and their `is not` forms. Comparing arrays, `arrayEncode` and saved stacks ignore the kind (#578)
- Script: the `as` operator converts a value: `as an array`, `as a sequence`, `as a dictionary`, `as a name`, `as a string`, `as a binary string`, `as a number`, `as an integer` and `as a boolean` (`put 1 as an integer into tV` makes `tV is strictly an integer` true) (#578)
- LCB: a handler that sets the new `sequencesAsLists` property to true hands its sequences to LCB as Lists, at any depth, through handler parameters, widget properties and `import widget`, so a widget whose state holds Lists can be copied through script (HyperXTalk issue 447). Without it every array goes in as an Array, as before (#578)
- JSON Codec 1.1.0: `jsonDecode` marks `[ ]` as a sequence and `{ }` as a dictionary, and `jsonEncode` and `jsonGuessShape` read those marks when given the option `marks`; without it they encode as before (#578)
