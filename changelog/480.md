- CI: a pull request marked ready a moment after a push can no longer pass its required checks with nothing built. Each job of the build, Web IDE and Web host workflows read the event's own copy of the draft state, which a push made to a draft still carries after the pull request is marked ready; that push's run could start after the ready run (one second after it on #478), cancel it and skip every job, and a skipped required check counts as passed. A first job, *Draft check*, now asks GitHub for the pull request's state at that moment and the other jobs follow its answer. A draft's run of these workflows now ends as passed, with a notice that nothing was built, where it ended as skipped (#480)
