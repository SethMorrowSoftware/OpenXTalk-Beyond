- File > Share Stack...: packs the stack for the OXT Community Stacks, the gallery of stacks that anybody can play in a web browser (github.com/SethMorrowSoftware/oxt-community-stacks). It asks for a title, the author's name, what the stack does and how others may use it, takes a picture of the stack, and writes one .zip to the Desktop, which the author attaches to a post on the forum; an admin of the gallery adds it from there, so sharing a stack needs no GitHub. A stack the gallery would refuse (never saved, with a password, with externals of its own) is not packed, and the window says why. Nothing of the stack is changed and nothing is sent anywhere. Not in the web IDE. New, and nothing else changes: `revIDEActionShareStack` and the script-only stack `revShareStack` (Toolset/palettes/share) (#509)
