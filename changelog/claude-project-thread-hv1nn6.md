- HTML5 standalones: a new Fonts setting on the Web pane. "Desktop fonts" adds Arimo, Tinos and Cousine (Google's open fonts, as wide as Arial, Times New Roman and Courier New; 1.9 MB more in standalone.zip), and the web engine draws Arial, Helvetica, Geneva, Verdana, Times, New York, Palatino, Courier, Monaco and the like in them, so text wraps where it wraps on the desktop; those names are then in the fontNames. The default, "Droid Sans for every font", builds standalones as before (#TBD)
- Stack Player: it has the desktop fonts, so stacks in Arial, Helvetica, Times or Courier (HyperCard stacks among them) lay out their text as on the desktop (#TBD)
- Tests: the web engine draws a desktop name in its stand-in only once that font is loaded, and as before once it is unloaded (tests/lcs/core/interface/web-desktop-fonts); the fonts, the runtime, the package, the builder and the Web pane name the same folder and value (tools/ci/tests/test_web_desktop_fonts.py) (#TBD)
