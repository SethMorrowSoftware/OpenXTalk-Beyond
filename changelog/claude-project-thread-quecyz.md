- Android: `the dnsServers` answers the DNS servers of the network the device is using, one a line, instead of throwing an error (198) as LiveCode 9.6.3's Android engine does and still does for a stack built with it. It needs the "ACCESS_NETWORK_STATE" application permission; without it, or with no network, it answers empty. Other platforms are unchanged. A new test checks that it answers without throwing, and the Android script tests' app asks for that permission
