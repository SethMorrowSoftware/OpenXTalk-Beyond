- SQLite 3.54.1 (was 3.51.3) for the SQLite database driver and the web engine, with the fixes of the 3.53 and 3.54 patch releases. Values come back as before: the driver keeps 15 significant digits on every connection (SQLITE_DBCONFIG_FP_DIGITS), and a small change in sqlite3.c makes quote() and the JSON functions follow it. What remains different: quote() of a real that 15 digits cannot hold writes 18 digits in the exponent form instead of 19 (both read back to the same number), and the 15th digit of a real above about 1e29 or below about 1e-29 is now rounded correctly where 3.51 was sometimes one off (#498)
- Tests: JSON arrays, quote() and text read as numbers through revDB keep 3.51's answers (tests/lcs/core/database/sqlite_values) (#498)
- expat 2.10.0 (was 2.2.0), which Skia uses on Android, with the fixes for the published vulnerabilities since 2.2.0; documents parse to the same events, and entity expansion of the "billion laughs" kind is refused (#498)
- FreeType 2.14.3 (was 2.10.4), which draws text in the web and Android engines, with the later fixes for CVE-2026-50811 and CVE-2026-95512. Text is measured and laid out as before: the advances, kerning and line metrics of every font in the repository are unchanged; hinted glyph outlines can differ by a pixel (#498)
- Tests: SQLite, expat and FreeType compiled from thirdparty/ give the answers of the versions before them (tools/ci/tests/test_thirdparty_libraries.py) (#498)
