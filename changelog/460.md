- HTML5 standalones: a new Fonts setting on the Web pane. - Stack Player: it has the desktop fonts, so stacks in Arial, Helvetica, Times or Courier (HyperCard stacks among them) lay out their text as on the desktop (#460)
- HTML5 standalones: a font from the Copy Files pane is read from the standalone's fonts folder whatever the defaultFolder is. It was found by its file name in the defaultFolder, and so only at startup: later its text drew in the face Skia found by the family's name, and a font named with its style ("Arimo Bold") in Droid Sans (#460)
