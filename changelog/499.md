- Browser: on Windows the browser's CEF code is libbrowser-cef.dll in Externals/CEF, built with MSVC v143; the engine stays on v141 (#499)
- CI: the Linux build compares what a script sees of the browser's htmlText and url with the lines recorded from 0.2.8-dp.1 (tools/ci/browser_compat_check.py) (#499)
- Linux: the browser needs four more system libraries, libcups2, libgbm1, libxkbcommon0 and libudev1 (cups-libs, mesa-libgbm, libxkbcommon and systemd-libs on Fedora); without one the launcher turns the browser off, as it does for the others (#499)
- Linux: the browser takes nothing from GTK, as CEF 74 took nothing (Chromium's fallback UI): Chromium 156 would load GTK 3 into the engine, which is a GTK 2 program (#499)
