- File > Community Stacks...: the OXT Community Stacks, the gallery of stacks that people share (oxt-stacks.github.io/oxt-community-stacks), in a window of the IDE. It fetches the gallery's list and shows it only when the list carries the gallery's signature (Ed25519, checked with SodiumXT against the gallery's public key, which the IDE holds); a list that is not signed, or that was changed after it was signed, is not shown, and the window says why. For each stack it shows the title, the author, the licence, what the stack does and what it reaches for (the internet, files, JavaScript), with Play in Browser (the stack on the gallery's site, where a browser's box keeps it away from the computer), Read Its Scripts (its scripts on the site) and Get a Copy. Get a Copy asks first, then brings the stack's download to Documents/OXT Community Stacks/<name>-<version>: the download and every file in it must be the bytes the signed list names (size and SHA-256), only the files the list names are written, each under a path the gallery's rules allow, and a folder that is there already is never written into. The copy can then be shown in its folder, or opened to look at with the pointer tool and its opening scripts not run; a copy named as one of the IDE's own stacks, or holding a substack so named, is not opened. Not in the web IDE. New, and nothing else changes: `revIDEActionCommunityStacks`, `revIDECommunityStacksGetCopy` and the script-only stack `revCommunityStacks` (Toolset/palettes/community) (#547)
