- xTalk Suite: webpxt is built in: org.openxtalk.library.webpxt, WebP pictures read into an image and written back through libwebp, lossy or lossless, with transparency, and animations a frame at a time; on Windows, Linux, macOS and Android, and linked into the web engines, so the web IDE, HTML5 standalones and the Stack Player run it (#614)
- xTalk Suite: barcodext is built in: org.openxtalk.library.barcodext, QR codes and barcodes read out of pictures and made as pictures, SVG or rows of squares, through zxing-cpp; on Windows, Linux, macOS and Android (its 32-bit Linux library, for x86 standalones, needs glibc 2.38), and linked into the web engines, so the web IDE, HTML5 standalones and the Stack Player run it (#614)
