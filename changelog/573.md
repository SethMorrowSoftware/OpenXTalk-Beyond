- JSON Codec Library (new, opt-in): jsonDecode, jsonDecodeWithShape and jsonEncode keep JSON arrays and objects apart. An xTalk array cannot say whether it came from [] or {}, so the library keeps a shape beside the value that records each container's kind, an object's key order and each number as it was written, and writes the same JSON back. jsonGuessShape, jsonSetKind and jsonKindOf read and change a shape. Nothing calls the library unless a script does: JsonImport, JsonExport, JSONToArray and ArrayToJSON give the results they gave before, and a script's own handler of the same name is still found first (#573)
- Tests: extensions/script-libraries/jsoncodec/tests/ reads every file of the JSON test suite, round trips 400 random documents and a 6000-level one, and runs JsonImport, JsonExport and mergJSON over the whole suite with the library loaded and not loaded, requiring the same results (#573)
