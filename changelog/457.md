- Android: an app can have an adaptive launcher icon, which Android 8.0 and newer draw in the launcher's own shape, and a themed one, which Android 13 and newer tint with the wallpaper's colours, through the "android,adaptive icon" (the foreground, a PNG file), "android,adaptive icon background" (#RRGGBB, #AARRGGBB or r,g,b) and "android,themed icon" (the monochrome picture) standalone settings; older Android shows the stack's Icon as before, and a stack without the settings is built as before (#457)
- Android check: the edge probe is built with a themed adaptive icon, and verify --adaptive-icon reads it in the package; the units run the builder's icon handlers on made-up pictures and colours (#457)
