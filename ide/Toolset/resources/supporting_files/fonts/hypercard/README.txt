ChicagoFLF.ttf
==============

A look-alike of Chicago, the Macintosh system font that HyperCard stacks
name most often. File > Import Stack shows the text of an imported
HyperCard stack that is set in Chicago in this font instead
(revHyperCardMacFonts in ide/Toolset/libraries/revhypercardscriptlibrary.livecodescript),
and only a stack imported that way loads it: the IDE does not load the
fonts of this folder at startup, as it does those of the folder above.

ChicagoFLF was made by Robin Casady for Casady & Greene's Fluent Laser
Fonts. This copy is version 2.0 of the file, as carried by the npm
package chicago.css 1.0.3 (by Bret Comnes), whose README gives the
designer's statement:

    PUBLIC DOMAIN (statement from original designer via email 2014/01/30)

    The FLF were created by various authors including myself and Mike
    Wright. When Casady & Greene, Inc. closed the rights went back to the
    authors. I created ChicagoFLF and CheckboxFLF. You are free to use
    them as you wish. I consider those two in the public domain.

    Regards,
    Robin Casady

The font file's own copyright and licence records say the same
("Public Domain").
