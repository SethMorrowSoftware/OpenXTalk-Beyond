PathMakeEmpty
(expression)
Creates a new empty path.

Syntax:
the empty path
----

Synonyms:

Params:

Examples:
// Initialize the path to empty
variable tPath as Path
put the empty path into tPath

// add a line to the path
move to point [0,50] on tPath
line to point [100,50] on tPath
----

Description:
Creates a new empty path.

Values:
An empty path.
