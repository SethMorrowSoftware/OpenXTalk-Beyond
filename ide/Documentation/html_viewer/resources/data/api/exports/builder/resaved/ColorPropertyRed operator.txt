ColorPropertyRed
(operator)
The red component of a color value.

Syntax:
the red of {mColor}
----

Synonyms:

Params:
mColor ( ): An expression which evaluates to a color.

Examples:
variable tColor
put color [0.75, 1.0, 0.5] into tColor

// Store the old red value
variable tRed
put the red of tColor into tRed

// Invert the intensity of the red color component
set the red of tColor to 1.0 - tRed
----

Description:
The red component of mColor  *Note:* The component value denotes the intensity of that component, expressed as a real number between 0 and 1.
