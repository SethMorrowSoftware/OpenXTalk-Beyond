dayFaceColor
(property)
Determines the color of the face of the clock during the day

Syntax:
get the dayFaceColor of {widget}
----
set the dayFaceColor of {widget} to {color}
----

Synonyms:

Params:

Examples:
Description:
Use the dayFaceColor property to get or set the color of the face of the clock during the day. To determine if the clock is displaying its daytime or night-time colors, use the read-only property isDay.
