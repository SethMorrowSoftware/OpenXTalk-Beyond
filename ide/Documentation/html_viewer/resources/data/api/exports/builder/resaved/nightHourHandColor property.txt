nightHourHandColor
(property)
Determines the color of the hour hand on the clock during the night

Syntax:
get the nightHourHandColor of {widget}
----
set the nightHourHandColor of {widget} to {color}
----

Synonyms:

Params:

Examples:
Description:
Use the nightHourHandColor property to get or set the color of the hour hand of the clock during the night. To determine if the clock is displaying its daytime or night-time colors, use the read-only property isDay.
