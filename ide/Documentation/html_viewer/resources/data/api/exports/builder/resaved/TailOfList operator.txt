TailOfList
(operator)
Returns the last element of Target.

Syntax:
the tail of {Target}
----

Synonyms:

Params:
Target ( ): An expression which evaluates to a list.

Examples:
variable tVar as List
put the empty list into tVar
push "first element" onto tVar
push "last element" onto tVar

variable tResult as String
if the tail of tVar is "last element" then
	put "success" into tResult
end if
----

Description:
Returns the first element of the list Target without modifying Target. ```	the tail of tVar``` is equivalent to using the IndexedElementOfList operator with index -1 ```	tVar[-1]```

Values:
The last element of Target
