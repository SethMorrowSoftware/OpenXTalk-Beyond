theme
(property)
Specifies the theme to use when drawing the control.

Syntax:
set the theme of tObject to tThemeName
----

Synonyms:

Params:

Examples:
set the theme of this stack to "native"
----

Description:
Use the theme property to control the general appearance of an object or control. It can be set on any object, including cards, stacks and controls. The currently supported values are "native" and "legacy". For an appearance that matches native apps for the platform an app is running on, use "native". The "legacy" setting preserves the appearance of older versions and is provided for backwards-compatibility.

Values:
The theme of an object or control is a name identifying the style to use when drawing it. 

OS:
mac,windows,linux,ios,android
