Architecture
(expression)
The architecture

Syntax:
the architecture
----

Synonyms:

Params:

Examples:
    if the architecture is "x86_64" then
        -- Do something x86_64 specific
    end if
----

Description:
Returns a string describing the instruction set architecture that is being used by the machine LiveCode is running on. The possible values are:  * "x86" - 32-bit x86 builds * "x86_64" - 64-bit x86 builds * "arm" - 32-bit arm builds * "arm64" - 64-bit arm builds * "js" - Emscripten
