Datagrid Commands
(glossary)
Datagrid commands are issued via 'dispatch' or 'send'.

Description:
To issue a command to the datagrid you can use 'dispatch' or 'send'. 'Dispatch' is preferred as it has the nice 'with' syntax for sending parameters. Using dispatch:  	put "value" into theArray["property"] 	dispatch "AddData" to group "DataGrid" with theArray  Using send:  	put "value" into theArray["property"] 	send "AddData theArray" to group "DataGrid"
