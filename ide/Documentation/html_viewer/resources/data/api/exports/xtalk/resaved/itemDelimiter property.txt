itemDelimiter
(property)
Specifies the character|character(s) used to separate items in chunk expression|chunk expressions.

Syntax:
set the itemDelimiter to {character(s)}
----

Synonyms:
itemdel

Params:

Examples:
set the itemDelimiter to numToChar(202)
----
set the itemDelimiter to tab
----
set the itemDelimiter to ";;"
----

Description:
Use the itemDelimiter property to divide text into chunk|chunks based on a delimit|delimiting character|character(s).

From version 7.0, itemDelimiter can be a string of one or several character|characters. chunk expression|Chunk expressions use the itemDelimiter to determine where one item ends and the next begins.

Since the itemDelimiter is a local property, its value is reset to comma when the current handler finishes execute|executing. It retains its value only for the current handler, and setting it in one handler does not affect its value in other handler|handlers it call|calls. 

Values:
From version 7.0, itemDelimiter can be a string of one or several character|characters. By default, the itemDelimiter property is set to comma. 

OS:
mac,windows,linux,ios,android
