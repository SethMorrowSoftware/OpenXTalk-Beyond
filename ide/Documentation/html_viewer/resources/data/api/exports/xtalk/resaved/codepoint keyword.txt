codepoint
(keyword)
Designates the integer identifier(s) associated with a Unicode character. 

Syntax:
codepoint
----

Synonyms:

Params:

Examples:
get codepoint 1 of tString
----
get the first codepoint of tString
----
repeat for each codepoint tCodepoint in tString
----

Description:
Use the codepoint keyword to refer to the integer identifier(s) associated with Unicode character  A codepoint is an integer identifier associted witha a Unicode character. A single character is composed of one or more codepoints.

The hierarchy of the new and altered chunk types is as follows:  byte w of codeunit x of codepoint y of char z of word ...

*Note:*  This chunk type is not of general utility.
