currentPage
(property)
Specifies the page being displayed in a multi-page EPS|EPS object.

Syntax:
set the currentPage of {EPS} to {pageNumber}
----

Synonyms:

Params:

Examples:
set the currentPage of EPS 6 to (1 + the currentPage of EPS 6)
----

Description:
Use the currentPage property to switch between the pages of an EPS|EPS object.

This property is supported only on Unix systems with Display PostScript installed. 

Values:
The currentPage of an EPS|EPS object is an integer between 1 and the EPS object's pageCount. 

OS:
linux,ios,android
