revIDEObjectsAreSelectable
(function)
Determine if a list of objects are selectable using the select command

Syntax:
revIDEObjectsAreSelectable({pObjects})
----

Synonyms:

Params:
pObjects ( ): A return delimited list of object references

Examples:
Description:
Returns true if all objects exist, are on an editable open stack and have the same owner.

Values:
True if the objects can be selected
