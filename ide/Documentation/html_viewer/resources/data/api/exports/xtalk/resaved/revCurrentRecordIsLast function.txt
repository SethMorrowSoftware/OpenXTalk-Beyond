revCurrentRecordIsLast
(function)
return|Returns whether the current record is the last record in a record set (glossary).

Syntax:
revCurrentRecordIsLast({recordSetID})
----

Synonyms:

Params:
recordSetID ( ): The number returned by the revQueryDatabase function when the record set was created.

Examples:
revCurrentRecordIsLast(3)
----
if revCurrentRecordIsLast(testMySQL) then exit repeat
----

Description:
Use the revCurrentRecordIsLast function to stop when you reach the end of the record|records.

If the operation is not successful, the revCurrentRecordIsLast function returns an error message that begins with the string "revdberr".

*Important:*  The revCurrentRecordIsLast function is part of the   Database library. To ensure that the function works in a   standalone application, you must include this   OpenXTalk custom library|custom library when you create your   standalone application|standalone. In the Inclusions pane of the   Standalone Application Settings window, make sure both the   "Database" library checkbox and those of the database drivers you are   using are checked.

Values:
The revCurrentRecordIsLast function returns true if there are no more record|records, false otherwise.
