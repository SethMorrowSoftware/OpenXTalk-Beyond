extensionDepsOrder
(command)
Use lc-compile to order Builder extensions by dependency.

Syntax:
extensionDepsOrder {pLCCompile},{pExtensionList}
----

Synonyms:

Params:
pLCCompile ( ): The path to the lc-compile program. If empty, this will be computed.
pExtensionList ( ): A list of Builder extensions to put in dependency order

Examples:
Description:
Use lc-compile to order Builder extensions by dependency.

Values:
Any error that occurred. The dependency-ordered list.
