soundChannel
(property)
Has no effect and is included for compatibility with imported HyperCard stacks.

Syntax:
set the soundChannel to {channelNumber}
----

Synonyms:

Params:

Examples:
Description:
In HyperCard, the soundChannel property determines which sound channel is used when Mac OS sound resource|resources are played. In OpenXTalk, this property has no effect.

By default, the soundChannel property is set to zero. A handler can set it to any number without causing a error|script error, but the change has no effect.
