intersect
(keyword)
Used with the selectionMode property to cause object|objects to be selected when any part of the object(glossary) is within the rectangle you drag.

Syntax:
intersect
----

Synonyms:

Params:

Examples:
set the selectionMode to "intersect"
----

Description:
Use the intersect keyword to change the way select|selecting behaves.

The intersect keyword applies only to selection|selections made with the Pointer tool. It does not affect text selection|selections in a field.

Values:

OS:
mac,windows,linux,ios,android
