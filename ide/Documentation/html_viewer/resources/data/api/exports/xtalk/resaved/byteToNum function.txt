byteToNum
(function)
Returns the numeric value of a byte.

Syntax:
the byteToNum of {byte}
----
byteToNum({byte})
----

Synonyms:

Params:
byte ( ): Any  that evaluates to a byte. If you specify a  containing more than one byte, all bytes but the first are ignored.

Examples:
byteToNum(byte 1 of tString)
----
if byteToNum(nextByte) = 0 then next repeat
----
numToByte(byteToNum("Z")) -- returns Z
----

Description:
Converts a single byte to a numeric value in the range 0-255  The byteToNum function is the inverse of the numToByte function.

Values:
The byteToNum function returns an integer between zero and 255. 

OS:
mac,windows,linux,ios,android
