populationVariance
(function)
return|Returns the population variance of a list of numbers.

Syntax:
populationVariance({numbersList})
----

Synonyms:
popvariance

Params:
numbersList ( ): A comma-separated list of numbers, or an expression that evaluates to such a list, or an array containing only numbers.

Examples:
populationVariance(8,10,12) -- returns 2.666667
----
put populationVariance(studentScores) into field "Population Variance"
----

Description:
Use the populationVariance function to analyze the amount of spread in a list of numbers.

The population variance is a measure of how widely distributed the numbers in the numbersList are.

If a math operation on finite inputs produces a non-finite output, an execution error is thrown. See math operation|math operations for more information.

Values:
The populationVariance function return|returns a number.
