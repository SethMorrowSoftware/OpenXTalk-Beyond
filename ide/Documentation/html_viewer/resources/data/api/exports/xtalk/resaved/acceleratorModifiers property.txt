acceleratorModifiers
(property)
Specifies one or more modifier key|modifier keys that must be pressed with the button shortcut key specified by the acceleratorKey property. 

Syntax:
set the acceleratorModifiers of {button} to {empty | {keys}}
----

Synonyms:
accelmods

Params:

Examples:
set the acceleratorModifiers of button 1 to shift
----
set the accelMods of button "Speak" to control,alt
----
set the accelMods of button it to command,shift
----

Description:
Use the acceleratorModifiers property, along with the acceleratorKey property, to specify a shortcut key combination for a button.

The following statements set up a shortcut for a button called "Calculate" :      set the acceleratorKey of button "Calculate" to "C"     set the acceleratorModifiers of button "Calculate" to alt,shift   When the user presses Alt-Shift-C (on Unix or Window systems) or Option-Shift-C (on Mac OS systems), the button's mouseUp handler is execute|executed.

*Cross-platform note:*  On Mac OS|Mac OS systems, the Control key and  Command key are equivalent when used with this property. The  option Key is likewise also equivalent to the Alt key.

Values:
The acceleratorModifiers of a button consists of a list of one or more keys, separated by commas. The keys can be any of "control", "command", "alt", "option", and "shift". If you use "command" as a key, it is converted to "control". If you use "option" as a key, it is converted to "alt".

By default, the acceleratorModifiers of a newly created button is empty.
