geometry management
(glossary)

Syntax:
Synonyms:
geometry management, geometry manager, manage geometry, managing geometry, manages geometry, managed geometry

Params:

Examples:
Description:
The process of moving and resizing control|controls in a stack window when the window size is changed.

You can perform geometry management in a resizeStack handler, or use the Geometry pane in each object|object's property inspector to specify geometry management settings.
