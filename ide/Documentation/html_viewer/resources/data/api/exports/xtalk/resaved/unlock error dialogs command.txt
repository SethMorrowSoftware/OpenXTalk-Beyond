unlock error dialogs
(command)
Sets the lockErrorDialogs property to false, allowing the error window to be displayed when an execution error occurs.

Syntax:
unlock error dialogs
----

Synonyms:

Params:

Examples:
unlock error dialogs
----
if the platform is not "Win32" then unlock error dialogs
----

Description:
Use the unlock error dialogs command to allow OpenXTalk to display the standard error window when an execution error occurs.

The unlock error dialogs command sets the lockErrorDialogs property to false. When all pending handler|handlers are finished execute|executing, the lockErrorDialogs property is set to false automatically. 

Values:

OS:
mac,windows,linux
