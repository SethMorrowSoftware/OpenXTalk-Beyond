image
(keyword)
Designates the Image tool, which is used to create new paint image|images. 

Syntax:
image
----

Synonyms:

Params:

Examples:
choose image tool
----

Description:
Use the image keyword together with the tool function to  create image|images.

When using the Image tool, the cursor is a crosshairs. This tool is used for creating images by clicking at one corner of the image and dragging to the opposite corner.

Values:

OS:
mac,windows,linux,ios,android
