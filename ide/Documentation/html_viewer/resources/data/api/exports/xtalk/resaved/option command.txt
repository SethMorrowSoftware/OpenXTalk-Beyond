option
(command)
Displays an option menu whose menu item|menu items are button|buttons in a stack.

Syntax:
option {stack}
----

Synonyms:

Params:
•	stack ( ): Any stack reference. The stack's first card must contain a button for each menu item in the option menu.
	
Examples:
option stack "Hot Text Items"
----
option stack (the menuStack of this image) -- custom property
----

Description:
Use the option command to display a stack menu as an option menu in situations where it is not possible to attach the menu to a button (for example, if the contents of the menu are not known in advance).

Use the option command in a mouseDown handler to display the menu :      on mouseDown         option stack "Help Menu"     end mouseDown   While the menu is displayed, the handler pauses.

The menu appears centered over the center of the control containing the handler. Choosing a menu item from the menu sends a mouseUp message to the stack.

Values:

OS:
mac,windows,linux
