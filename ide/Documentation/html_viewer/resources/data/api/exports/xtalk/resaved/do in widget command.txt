do in widget
(command)
Executes a list of statements within a widget.

Syntax:
do {script} in {widget}
----

Synonyms:

Params:
script (string ): The code to execute within the widget.
widget ( ): A widget reference

Examples:
-- Use JavaScript to hide "myButton" in the page displayed in a browser widget.
do "document.getElementById('myButton').hidden = 'hidden'" in widget "myBrowser"
----

Description:
Use the do in widget command to execute statements in a widget. Builder VM sends a "OnDo" message with script as parameter to the widget, which can then handle that messages to run the code appropriately.

Values:

OS:
mac,windows,linux,ios,android
