surround
(keyword)
Used with the selectionMode property to cause object|objects to be selected only when the entire object(glossary) is within the rectangle you drag.

Syntax:
surround
----

Synonyms:

Params:

Examples:
set the selectionMode to surround
----

Description:
Use the surround keyword to change the way select|selecting behaves.

The surround keyword applies only to selection|selections made with the Pointer tool. It does not affect text selection|selections in a field.

Values:

OS:
mac,windows,linux,ios,android
