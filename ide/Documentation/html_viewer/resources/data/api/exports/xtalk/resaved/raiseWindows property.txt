raiseWindows
(property)
Set the raiseWindows global property to true if you want to force xTalk's windows to move as one layer.

Syntax:
set the raiseWindows to {true | false}
----
get the raiseWindows
----

Synonyms:

Params:

Examples:
put the raiseWindows into tWindowsRaise
----
set the raiseWindows to true
----
set the raiseWindows to windowsRaise()
----

Description:
When the raiseWindows is set to true, xTalk's windows move as one layer, this means it will not be possible for another application to become interleaved with xTalk's windows, as is possible if the property is set to false.

Values:

OS:
mac,windows,linux
