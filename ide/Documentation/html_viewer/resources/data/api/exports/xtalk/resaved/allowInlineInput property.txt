allowInlineInput
(property)
Specifies whether the user can type non-Roman text directly into a field. 

Syntax:
set the allowInlineInput to {true | false}
----

Synonyms:

Params:

Examples:
set the allowInlineInput to true
----
set the allowInlineInput to the letUsersType of this stack
----

Description:
Use the allowInlineInput property to determine the method by which the user can enter double-byte character|double-byte text.

If the allowInlineInput property is set to true, the user can type double-byte character|double-byte characters (used for languages that do not use the Roman alphabet, such as Chinese, Japanese, and Korean) directly into field(object)|fields.

If the allowInlineInput is false, if the insertion point is in a field(keyword) and a double-byte language is currently selected, a text-entry palette appears where the user can enter the characters. (This palette is displayed by the operating system's language software, not by OpenXTalk.) When the user presses Enter, the characters are placed in the field(keyword).

Values:
The allowInput property is true or false. By default, the allowInlineInput is true. 

OS:
mac,windows
