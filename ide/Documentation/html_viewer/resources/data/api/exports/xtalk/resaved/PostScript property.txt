postScript
(property)
Specifies the actual PostScript code associated with an EPS|EPS object. 

Syntax:
set the postScript of {EPSObject} to
----

Synonyms:

Params:

Examples:
set the postScript of EPS "To Print" to field "Result"
----

Description:
Use the postScript property to examine or change the PostScript code of an EPS|EPS object.

This property is supported only on Unix systems with Display PostScript installed. 

Values:
The postScript of an EPS|EPS object is a string. By default, the postScript property of newly created EPS|EPS objects is set to empty. 

OS:
linux
