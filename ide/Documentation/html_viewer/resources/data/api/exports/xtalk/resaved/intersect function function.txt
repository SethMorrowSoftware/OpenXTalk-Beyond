Description:
Use the intersect function to determine whether one object(glossary) obscures part of another object(glossary), or whether one object(glossary) is over another object(glossary).

The intersect function uses screen coordinates for stacks and card|cards, and relative coordinates|coordinates for control|controls. This means that if one object|object is a stack or card|card and the other is a control|control, the intersect function does not return|return a reliable result.
