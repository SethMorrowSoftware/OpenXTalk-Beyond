hideBackdrop
(property)
Set the hideBackdrop global property to true if you want a OpenXTalk application's backdrop to be hidden when another application is activated. 

Syntax:
set the hideBackdrop to { true | false }
----
get the hideBackdrop
----

Synonyms:

Params:

Examples:
put the hideBackdrop into tBackdropHide
----
set the hideBackdrop to true
----
set the hideBackdrop to the cBackdropHide of me
----

Description:
When the hideBackdrop is set to to true, a OpenXTalk application's backdrop will be hidden if a different application is activated (brought to the front by a user). If it is set to false, the backdrop will stay visible behind the newly activated application.

When a OpenXTalk application is minimized, the backdrop of the application will always be hidden.

Values:

OS:
mac,windows,linux
