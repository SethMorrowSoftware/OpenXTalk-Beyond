undoChanged
(message)
Sent to the current card when the Undo action changes.

Syntax:
undoChanged
----

Synonyms:

Params:

Examples:
on undoChanged
  global lastFieldState
  put field "Edit" into lastFieldState
end undoChanged
----

Description:
Handle the undoChanged message if you want to intercept the "Undo" menu item, providing your own Undo stack.

Undoable actions include painting actions, deletion of objects, moving of controls, and editing actions in a field. When the user performs one of these actions, thus changing what happens as a result of choosing Edit ? Undo from the menubar, OpenXTalk sends the undoChanged message to the current card.
