commandChar
(property)
Has no effect and is included for compatibility with imported HyperCard stacks.

Syntax:
set the commandChar of {menuItem} to {character}
----

Synonyms:

Params:

Examples:
Description:
In HyperCard, the commandChar property determines the Command  key combination for a menu item.

A handler can set the commandChar to any value without causing a error|script error, but the actual Command key combination is not changed.

ios,android
