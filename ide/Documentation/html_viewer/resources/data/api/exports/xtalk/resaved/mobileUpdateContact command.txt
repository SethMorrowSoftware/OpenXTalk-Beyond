mobileUpdateContact
(command)
Allows the user to create a contact, based on some existing contact data. 

Syntax:
mobileUpdateContact {contactArray}, [{contactTitle}], [{message}], [{alternateName}]
----

Synonyms:

Params:
contactArray (array ): 
contactTitle ( ): The title that is to appear at the top of the user interface (iOS only)
message ( ): Any message that is to be added to the user interface.
alternateName ( ): An alternate name that is to be displayed in the contact user interface.

Examples:
put "Just adding this" into tContact["note"]
put "Jobs Ave" into tContact["address"]["home"][1]["street"]
put "Job City" into tContact["address"]["home"][1]["city"]
put "test@OpenXTalk.org" into tContact["email"]["home"][1]
mobileUpdateContact tContact
----

Description:
Allows the user to create a contact in the contact list, based on some existing contact information. The contact information is collected in a nested array structure that is defined as follows:  Use the mobileUpdateContact command to display a native iOS or Android contact update dialog that allows the user to create a contact list entry. Pre-existing contact information is provided as an array to this command. 

Values:
The ID of the created contact is returned as the result. If no new contact is created, then empty is returned. 

OS:
ios,android
