printTextAlign
(property)
Has no effect and is included for compatibility with imported HyperCard stacks.

Syntax:
set the printTextAlign to {left | center | right}
----

Synonyms:

Params:

Examples:
Description:
In HyperCard, the printTextAlign property specifies the alignment of printed text. In OpenXTalk, only card(object)|cards can be printed, and the alignment of text on the card(keyword) is determined by the card(keyword) layout and the properties of its object|objects.

By default, the value of printTextAlign is center. A handler can set the property, but the new setting has no effect.
