Syntax:
Synonyms:
color specifier, color reference, color descriptor

Params:

Examples:
Description:
Any valid way of describing a particular color that OpenXTalk can understand.

Colors can be referred to by color name, HTML -style specification, or as three comma-separated numbers between zero and 255 (one for each of red, blue, and green).
