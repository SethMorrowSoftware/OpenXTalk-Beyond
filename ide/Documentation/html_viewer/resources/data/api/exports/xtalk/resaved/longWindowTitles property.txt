longWindowTitles
(property)
Has no effect and is included for compatibility with imported HyperCard stacks.

Syntax:
set the longWindowTitles to {true | false}
----

Synonyms:

Params:

Examples:
Description:
In HyperCard, the longWindowTitles property determines whether a stack window|stack window's title bar shows the  absolute file path|full path to a stack, or only the stack|stack's name. In OpenXTalk, the stack|stack's label property is shown as the  window title; if the label is empty, the short version of the  stack|stack's name property is shown.

A handler can set the longWindowTitles without causing a error|script error, but the actual window title is not changed. The default value is false.
