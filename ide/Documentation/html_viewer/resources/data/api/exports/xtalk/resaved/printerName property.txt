printerName
(property)
Reports the name of the currently selected printer.

Syntax:
set the printerName to {string}
----
get the printerName
----

Synonyms:

Params:

Examples:
set the printerName to "PostScript Printer"
----
if the printerName is not empty then
  enable button "Print" of me
end if
----

Description:
Use the printerName property to determine or set the printer that will be used by OpenXTalk.

Setting the printerName to empty will reset the printer to the system default, and all printer settings to the default for that printer.

To have an effect, this property must be set before calling  open printing. 

Values:
Setting the printerName will attempt to select the printer with the given name and reset all printer properties to the defaults for that printer. If the printer cannot be found, the result is set to "unknown printer".  The printerName property returns the name of the currently selected printer, or empty if printing is not available. By default, the name of the system's default printer is returned. 

OS:
mac,windows,linux
