finally
(keyword)
Used within a try control structure to contain statement|statements that are execute|executed whether or not there was an error.

Syntax:
finally
----

Synonyms:

Params:

Examples:
finally
----

Description:
Use the finally keyword to designate one or more statement|statements that are to be execute|executed within a try control structure.

The finally keyword appears on a line by itself, and is followed by a list of statement|statements. The statement|statements in the finally section are execute|executed whether or not there was an error while execute|executing the try control structure.

The finally section is always execute|executed even if the try control structure contains an exit or pass statement, so it can be used for final cleanup actions such as deleting variable|variables.

The finally section is optional in a try control structure.
