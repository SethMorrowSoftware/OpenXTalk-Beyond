pageHeights
(property)
Reports the height of each printed page if a field is printed.

Syntax:
get the pageHeights of {field}
----

Synonyms:

Params:

Examples:
set the height of field 1 to line 1 of the pageHeights of field 1
----

Description:
Use the pageHeights property to determine how much to scroll a field(keyword) during printing.

The value reported by the pageHeights property is a list of numbers separated by returns. Each number is the height in pixels of a page full of text.

You can use the pageHeights property to print the entire contents of a field(keyword) by printing the field(keyword), setting the field(object)|field's vScroll to the first line of the pageHeights, printing the field(keyword) again, setting the vScroll to the current vScroll plus line 2 of the pageHeights, and so on.

The computations used by the pageHeights property assume the field(object)|field's borderWidth property is set to zero and its margins is set to 6.

Values:
The pageHeights of a field is a list of integer|integers, one per line. This property is read-only and cannot be set.
