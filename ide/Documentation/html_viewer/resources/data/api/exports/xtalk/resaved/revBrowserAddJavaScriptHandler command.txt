revBrowserAddJavaScriptHandler
(command)
Adds the named handler to the 'OpenXTalk' object within the current JavaScript context of the browser.

Syntax:
revBrowserAddJavaScriptHandler {instanceID}, {handlerName}
----

Synonyms:

Params:
instanceID ( ): the ID of the browser instance returned by the  function.
handlerName ( ): the name of a OpenXTalk handler in the script of the card / stack displaying the browser.

Examples:
local tBrowserID
put revBrowserOpenCef(the windowId \
      of this stack, "http://www.OpenXTalk.org" ) into tBrowserID
revBrowserAddJavaScriptHandler tBrowserID, "myOpenXTalkHandler"
----

Description:
The revBrowserAddJavaScriptHandler adds the named handler to the 'OpenXTalk' object within the current JavaScript context of the browser.

The revBrowserAddJavaScriptHandler function will make the named OpenXTalk handler visible to JavaScript within the browser as a function belonging to the global JavaScript 'OpenXTalk' object. Calling this JavaScript function will result in a call to the OpenXTalk handler, which will be passed the browser instance as the first parameter followed by any parameters given to the JavaScript function.

A OpenXTalk card has the following handler:      on myOpenXTalkHandler pID, pArg1, pArg2         answer "Browser ID" && pID &&         "called myOpenXTalkHandler with arguments" && pArg1 && "and" && pArg2     end myOpenXTalkHandler   Registered within the JavaScript context with the following command:      revBrowserAddJavaScriptHandler tBrowserID, "myOpenXTalkHandler"   The JavaScript code within the browser can then call the OpenXTalk handler via the registered function:       if (tIsRevBrowser)         OpenXTalk.myBrowserHandler(tValue1, tValue2);

Values:

OS:
mac,windows
