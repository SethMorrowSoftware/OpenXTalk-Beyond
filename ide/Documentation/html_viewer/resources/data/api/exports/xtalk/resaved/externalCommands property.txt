externalCommands
(property)
Lists the available external|external commands for a stack.

Syntax:
get the externalCommands of {stack}
----

Synonyms:

Params:

Examples:
answer the externalCommands of stack "Basics"
----
if myExternal is among the lines of the externalCommands \
  of this stack then do myExternal
----

Description:
Use the externalCommands property to find out whether a particular external|external command is available for use in handler|handlers, or to list all the available external|external commands.

You use an external command in a handler the same way you use one of xTalk's built-in commands.

Values:
The externalCommands of a stack reports a list of available external|external commands, one per line. This property is read-only and cannot be set.

windows,linux
