iphoneReachabilityTarget
(function)
Returns the server currently being monitored

Syntax:
iphoneReachabilityTarget
----

Synonyms:

Params:

Examples:
get iphoneReachabilityTarget()
----

Description:
Use the iphoneReachabilityTarget function to determine the server currently being monitored for network connectivity.

The iphoneReachabilityTarget function returns the server currently being monitored for network connectivity. If there is no server being monitored the function returns empty.

Values:
The server currently being monitored, empty if no server is currently being monitored. 

OS:
ios
