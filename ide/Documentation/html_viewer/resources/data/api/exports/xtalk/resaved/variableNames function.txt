variableNames
(function)
return|Returns a list of all parameter|parameters,  local variable|local variables, and global variable|variables.

Syntax:
the variableNames
----
variableNames()
----

Synonyms:

Params:

Examples:
the variableNames
----
repeat with x=1 to the number of items of line 4 of the variableNames
----

Description:
Use the variableNames function to find out which sources of value are available to the current handler, or to see whether a variable name is available for use.

Values:
The variableNames function return|returns a value consisting of four lines :  1. Parameters passed to the current handler (including leading '@' for parameters passed by-reference) 2. Local variables created in the current handler 3. Local variables created in the current script but outside all handlers  4. Global variables  Within each line, the variable or parameter names are separated by commas.  

OS:
mac,windows,linux,ios,android
