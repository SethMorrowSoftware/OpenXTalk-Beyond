u3eject
(message)
Sent to the first stack after the engine receives a U3 stop message from the U3 LaunchPad.

Syntax:
u3eject {pType}
----

Synonyms:

Params:
pType (enum ): How the U3 drive was ejected.

Examples:
on u3eject
    saveFiles
end u3eject
----

Description:
When the U3 LaunchPad requests an application stops, it sends a stop message to the OpenXTalk engine. The engine will send a u3eject message to the first stack.

Values:

OS:
windows
