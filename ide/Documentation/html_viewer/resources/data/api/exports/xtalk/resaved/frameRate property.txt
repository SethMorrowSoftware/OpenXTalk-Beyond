frameRate
(property)
Specifies the delay between frame|frames when playing a video clip.

Syntax:
set the frameRate of {videoClip} to {timeDelay}
----

Synonyms:

Params:

Examples:
set the frameRate of videoClip 1 to 100
----

Description:
Use the frameRate property to speed up or slow down a movie.

The frameRate is the number of milliseconds to wait between frame|frames. If the frameRate is zero, OpenXTalk uses the frame rate built into the movie.

The setting of this property has no effect on Windows systems.

Values:
The frameRate of a video clip is a non-negative integer. By default, the frameRate property of newly created  video clip|video clips is set to zero. 

OS:
mac,linux,ios,android
