revGetSpeechVolume
(function)
Returns the current speech volume

Syntax:
revGetSpeechVolume()
----

Synonyms:

Params:

Examples:
put revGetSpeechVolume() into tVolume
----

Description:
Use the revGetSpeechVolume function to find out what the current volume that OpenXTalk will speak at is.

The default volume is 100 on both Windows and Mac OS X.

*Important:*  The revGetSpeechVolume function is part of the   Speech library. To ensure that the function works in a   standalone application, you must include this   OpenXTalk custom library|custom library when you create your   standalone application|standalone. In the Inclusions pane of the   Standalone Application Settings window, make sure the "Speech"   library checkbox is checked.

Values:
The revGetSpeechVolume function returns a number between 0 and 100. 

OS:
mac,windows
