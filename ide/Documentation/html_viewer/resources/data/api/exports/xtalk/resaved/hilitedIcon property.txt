hilitedIcon
(property)
Specifies an image to display in a button when the button is highlight|highlighted. 

Syntax:
set the hilitedIcon of {button} to {{imageID} | {imageName}}
----

Synonyms:
hiliteicon

Params:

Examples:
set the hilitedIcon of button "Management" to 343
----

Description:
Use the hilitedIcon property to change a button|button's appearance when it is highlight|highlighted.

When the button is highlighted, the hilitedIcon is displayed within the button's rectangle.

Values:
The hilitedIcon property is the ID or name of an image to use for an icon. OpenXTalk looks for the specified image first in the current stack, then in other open stacks. By default, the hilitedIcon property of newly created button|buttons is set to zero.  

OS:
mac,windows,linux,ios,android
