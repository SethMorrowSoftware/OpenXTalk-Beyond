Description:
mergMicrophone is a basic wrapper around the iOS AVAudioRecorder class, enabling audio recording to be performed in iOS applications. It is a modified version of rremicrophone which is provided as part of the Externals SDK. The rremicrophone license requires modified source versions to be distributed without the rre handler prefix or com_runrev class prefix.
