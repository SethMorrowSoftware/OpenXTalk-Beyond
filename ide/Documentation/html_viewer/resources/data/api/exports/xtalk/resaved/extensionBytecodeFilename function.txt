extensionBytecodeFilename
(function)
Return the default bytecode output filename

Syntax:
extensionBytecodeFilename({pLCCompile},{pUseVersion})
----

Synonyms:

Params:
pLCCompile ( ): The path to the lc-compile program. If empty, this will be computed.
pUseVersion ( ): Whether to use the bytecode version as part of the filename or not. Defaults to true.

Examples:
Description:
Return the default bytecode output filename

Values:
Either "module.lcm" or "module.lc-compile_version.lcm" depending on the value of the pUseVersion parameter.
