loadedExtensions
(function)
return|Returns a list of the currently loaded extensions.

Syntax:
the loadedExtensions
----
loadedExtensions()
----

Synonyms:

Params:

Examples:
put the loadedExtensions
----
if "com.xtalkextensions.OpenXTalk.switchButton" is among the lines of the loadedExtensions then
    create widget as "com.xtalkextensions.OpenXTalk.switchButton"
end if    
----

Description:
Use the loadedExtensions function to find out which  Builder extension|extensions are loaded, in order to determine  (for library extension|libraries) if its public handlers are available  in the message path, or (for widget|widgets) if it is available to  create with the create widget command.

Each line of the list returned by the loadedExtensions function is the kind of the corresponding OpenXTalk Builder extension|extension.

Values:
The loadedExtensions function return|returns a list of the loaded Builder extension|extensions, one per line. 

OS:
mac,windows,linux,ios,android
