multiEffect
(property)
Has no effect and is included for compatibility with imported SuperCard projects.

Syntax:
set the multiEffect to {true | false}
----

Synonyms:

Params:

Examples:
Description:
In SuperTalk, the multiEffect property determines whether multiple visual effects are played in succession or interleaved. In OpenXTalk, visual effects are always played back in succession, one after the other.

The multiEffect property is always set to false. A handler can set it to any value without causing a error|script error, but the actual value is not changed.
