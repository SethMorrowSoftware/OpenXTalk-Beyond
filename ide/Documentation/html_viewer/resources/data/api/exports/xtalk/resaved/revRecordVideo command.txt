revRecordVideo
(command)
Records video from a video camera to a file.

Syntax:
revRecordVideo {filePath}
----

Synonyms:

Params:
filePath ( ): The name and location of the file that will hold the recorded video data. If you specify a name but not a location, the engine assumes the file is in the defaultFolder.

Examples:
revRecordVideo "/Disk/Folder/file.mov"
----
revRecordVideo "mymovie.avi"
----
revRecordVideo theFileName
----

Description:
Use the revRecordVideo command to record a movie file.

You must use the revInitializeVideoGrabber command to open the video grabber before you can use the revRecordVideo command.

The recorded video is stored in AVI format.

If the video grabber was already recording video to a file, executing the revRecordVideo command again stops that recording and starts a new one. To stop recording the video input, use the revStopRecordingVideo command.

*Important:*  The revRecordVideo command is part of the   Video library. To ensure that the command works in a   standalone application, you must include this   OpenXTalk custom library|custom library when you create your   standalone application|standalone. In the Inclusions pane of the   Standalone Application Settings window, make sure the  "Video Grabber"   library checkbox is checked.
