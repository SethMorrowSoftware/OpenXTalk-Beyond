unlock moves
(command)
Sets the lockMoves property to false, allowing object(glossary) motions caused with the move command to be seen.

Syntax:
unlock moves
----

Synonyms:

Params:

Examples:
unlock moves
----
if the ticks > timeToGo then unlock moves
----

Description:
Use the unlock moves command to begin all pending move command|commands at once.

The unlock moves command sets the lockMoves property to false. When all pending handler|handlers are finished execute|executing, the lockMoves property is automatically set to false.

Values:

OS:
mac,windows,linux,ios,android
