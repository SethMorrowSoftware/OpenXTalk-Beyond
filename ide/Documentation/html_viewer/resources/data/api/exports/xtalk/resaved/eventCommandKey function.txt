eventCommandKey
(function)
return|Returns the state of the Command key.

Syntax:
the eventCommandKey
----
eventCommandKey()
----

Synonyms:

Params:

Examples:
put the eventCommandKey into keyState
----
if the eventCommandKey is down then exit rawKeyDown
----

Description:
Use the eventCommandKey function(control structure) to check whether the Command key was pressed at the time the current event was dispatched.

If you want to check the state of the Command key at the current time, rather than when the event was dispatched, use the commandKey function.

On Unix and Windows systems, the eventCommandKey function return|returns the same value as the eventControlKey function(control structure): the two function(glossary)|functions are synonyms.

 **Warning**: the value of this function is undefined after performing  a wait operation; it may no longer be the same as the value when the  event was dispatched.

Values:
The eventCommandKey function return|returns down if the key was down at the time the current event was generated or up otherwise.
