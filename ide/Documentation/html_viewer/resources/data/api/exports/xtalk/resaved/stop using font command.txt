stop using font
(command)
Unloads a font file from memory.

Syntax:
stop using font file {fontFile}
----

Synonyms:

Params:
fontFile ( ): 

Examples:
stop using font file "C:/myFontFolder/myCustomFont.ttf"
----

Description:
The stop using font command unloads a font file from memory. The fontFile is the path of the font file to unload  *Note:* The fontNames function will return the name of all   available fonts and the fontFilesInUse property will return the   fill paths of the loaded font files. To determine the name of the   newly unloaded font, compare the value of the fontNames before and   after unloading the font.

Values:
The stop using font command puts empty into the result if successful. Otherwise an error string is put into the result. 

OS:
mac,windows
