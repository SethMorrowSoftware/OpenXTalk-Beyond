extensionValidateLCEPackage
(command)
Validate an extension package

Syntax:
extensionValidateLCEPackage {pPackage},{rManifestDataA}
----

Synonyms:

Params:
pPackage ( ): The .lce package to validate
rManifestDataA ( ): The basic manifest data extracted from the package

Examples:
Description:
Use the extensionValidateLCEPackage command to naively validate the contents of an .lce package. extensionValidateLCEPackage checks if there is a file that looks like the main extension (either a compiled Builder module file or a stack), that it contains a manifest XML file and that the manifest contains the minimum required information, namely the name, version, author, type, and title.

The manifest information is returned in the rManifestDataA out parameter.

Values:
If the package was deemed invalid, the result contains the reason why the package failed validation.
