DiffCompareFiles
(function)
Produce a diff representing the changes between two text files

Syntax:
DiffCompareFiles({pFrom},{pTo},{pContext})
----

Synonyms:

Params:
pFrom ( ): The original source file. The produced diff will describe how to transform the contents of this file.
pTo ( ): The updated source file. This will be compared to pFrom to produce the output diff.
pContext ( ): The number of unchanged lines to include before / after each change in the diff.

Examples:
----

Description:
Compare two files, producing a string representing the changes between them in unified-diff format.

Values:
A string representing the changes between pFrom and pTo in unified diff format.
