armedIcon
(property)
Specifies an image to display in a button when the mouse pointer enters it.

Syntax:
set the armedIcon of {button} to {{imageID} | {imageName}}
----

Synonyms:

Params:

Examples:
set the armedIcon of button "Trigger" to 2245
----

Description:
Use the armedIcon property to change a button|button's appearance when it is armed. Do not use this property to create hover icon effects, instead use the hoverIcon property.

If the button's autoArm property is false, the setting of the armedIcon property has no effect.

Values:
The armedIcon property is the ID or name of an image to use for an icon. OpenXTalk looks for the specified image first in the current stack, then in other open stacks. By default, the armedIcon property of newly created button|buttons is set to zero. 

OS:
mac,windows,linux,ios,android
