value
(function)
return|Returns the value of an expression.

Syntax:
the value of {expression}
----
value({expression} [, {object}])
----

Synonyms:

Params:
•	expression ( ): Any expression.
•	object ( ): Any object reference.
	
Examples:
the value of 22 + 3 -- returns 25
----
value(myVariable) -- returns value of the contents of myVariable
----
the value of the selectedLine -- returns the actual text of the line
----
value("the name of me", card 1) -- returns name of card 1
----

Description:
Use the value function to evaluate an expression, or to force OpenXTalk to evaluate an expression within a statement.

For example, "button 3" refers to button 3 on the current card, not the card where the object(glossary) is located.

This means that you must be careful about literal string|string literals that contain operator|operators such as "and".
