markChar
(property)
Has no effect and is included for compatibility with imported HyperCard stacks.

Syntax:
set the markChar of {menuItem} to {character}
----

Synonyms:

Params:

Examples:
Description:
In HyperCard, the markChar property places a character (such as a checkmark) next to a menu item.

A handler can set the markChar to any value without causing a error|script error, but the actual appearance of the menu item is not changed.

Values:

ios,android
