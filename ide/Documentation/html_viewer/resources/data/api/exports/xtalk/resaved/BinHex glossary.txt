BinHex

Synonyms:
hqx, .hqx, bin hex, binhex, binhexed, binhexing, binhexes

Params:

Examples:
Description:
A format for transforming binary file|binary files by encoding them as ASCII text for transfer over 7-bit links (which garble non-text file|files).

The names of BinHex files usually end in ".hqx".
