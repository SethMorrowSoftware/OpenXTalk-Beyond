screenName
(function)
return|Returns the name of the current screen.

Syntax:
the screenName
----
screenName()
----

Synonyms:

Params:

Examples:
the screenName
----
put "myApp -d" && the screenName into commandLine
----

Description:
Use the screenName function to control where applications that OpenXTalk starts up should appear.

On Unix systems, the screenName function return|returns the string provided by the XDisplayName function call. When starting a process with the open process command or the shell function, if you want the process to appear on the same screen as OpenXTalk, use the value return|returned by the screenName as the argument to the -d option.

This function does not return a useful value on Mac OS and Windows systems. 

Values:
The screenName function return|returns a string.

mac,windows,linux
