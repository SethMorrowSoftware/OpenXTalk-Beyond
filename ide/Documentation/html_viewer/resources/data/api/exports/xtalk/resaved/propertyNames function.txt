propertyNames
(function)
return|Returns a list of all built-in properties in OpenXTalk.

Syntax:
the propertyNames
----
propertyNames()
----

Synonyms:

Params:

Examples:
the propertyNames
----
if it is among the lines of the propertyNames then beep
----

Description:
Use the propertyNames function to check whether a particular property already exists in OpenXTalk, to avoid using a  reserved word for your own custom property|custom properties.

The propertyNames function return|returns all the property|properties that can be used in OpenXTalk, including synonyms. 

Values:
The propertyNames function return|returns a list of property names, one per line. 

OS:
mac,windows,linux,ios,android
