arrow
(constant)
Equivalent to the number 29.

Syntax:
arrow
----

Synonyms:

Params:

Examples:
set the cursor to arrow
----

Description:
Use the arrow constant to set the cursor(property) to an arrow shape.

The following two statements are equivalent:      set the cursor to arrow     set the cursor to 29   However, the first is easier to read and understand in OpenXTalk.

*Important:*  If you use the arrow cursor(property) or other  standard cursor(glossary)|cursors in your application, you must  include the cursors when you create your  standalone application|standalone. Make sure the "Cursors"  option on the Inclusions section on the General screen of the  Standalone Application Settings window is checked.

Values:

OS:
mac,windows,linux,ios,android
