log10
(function)
return|Returns the base-10 logarithm of a number.

Syntax:
the log10 of {number}
----
log10({number})
----

Synonyms:

Params:
number ( ): A positive number, or an expression that evaluates to a positive number.

Examples:
log10(1000) -- returns 3, because 10^3 = 1000
----
log10(0.1) -- returns -1
----
log10(163)
----

Description:
Use the log10 function to obtain a logarithm.

The logarithm of a number is the power to which 10 must be raised to obtain the number : 10^log10(number) is equal to number.

If a math operation on finite inputs produces a non-finite output, an execution error is thrown. See math operation|math operations for more information.

Values:
The log10 function return|returns a number.
