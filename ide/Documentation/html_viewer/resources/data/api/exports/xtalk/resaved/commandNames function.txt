commandNames
(function)
return|Returns a list of all built-in command|commands in OpenXTalk. 

Syntax:
the commandNames
----
commandNames()
----

Synonyms:

Params:

Examples:
the commandNames
----
if field "Name" is among the lines of the commandNames then exit repeat
----

Description:
Use the commandNames function to check whether a particular command already exists in OpenXTalk, to avoid using a reserved word for your own custom handler|handlers.

The commandNames function return|returns all the command|commands that can be used in OpenXTalk, including synonyms.

Values:
The commandNames function return|returns a list of command names, one per line.

mac,windows,linux,ios,android
