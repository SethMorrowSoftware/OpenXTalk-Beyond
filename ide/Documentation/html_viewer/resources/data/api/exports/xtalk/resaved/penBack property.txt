penBack
(property)
Has no effect and is included for compatibility with imported SuperCard projects.

Syntax:
set the penBack [of {object}] to {colorNumber}
----

Synonyms:

Params:

Examples:
Description:
In SuperCard, the penBack property specifies the color used to draw borders. In OpenXTalk, the border color is determined by the borderColor property.

The penBack property is always set to empty. A handler can set it to any value without causing a error|script error, but the actual value is not changed.
