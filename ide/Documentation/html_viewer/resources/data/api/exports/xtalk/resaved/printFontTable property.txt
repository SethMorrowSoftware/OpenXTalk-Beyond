printFontTable
(property)
Specifies the PostScript font|fonts that are substituted for screen font|fonts when you print on a PostScript printer.

Syntax:
set the printFontTable to {fontCorrespondencesList}
----

Synonyms:

Params:

Examples:
set the printFontTable to bookmanFonts & return & arialFonts
----

Description:
Use the printFontTable property to specify substitution mappings for nonstandard font|fonts you use, or to change the standard font substitutions for better results.

Each line of the printFontTable corresponds to one screen font and contains the following items, separated by commas:  * The name of an X11 screen font * The name of the PostScript font to use in its place for printing  * The name of the normal style for that font * The name of the bold style for that font * The name of the italic style for that font * The name of the bold italic style for that font   By default, the printFontTable property uses a mapping between the standard MIT X11R4 font|fonts and the PS35 font set.

The setting of this property has no effect on Mac OS and Windows systems. 

Values:
The printFontTable is a list of font names and their print equivalents, one per line.
