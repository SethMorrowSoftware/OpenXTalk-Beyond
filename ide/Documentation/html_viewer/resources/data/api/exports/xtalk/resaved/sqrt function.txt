sqrt
(function)
return|Returns the square root of a number.

Syntax:
the sqrt of {number}
----
sqrt({number})
----

Synonyms:

Params:
number ( ): Any non-negative number, or an expression that evaluates to such a number. 

Examples:
sqrt(9) -- returns 3
----
put sqrt(sideA^2 + sideB^2) into hypotenuseLength
----

Description:
Use the sqrt function to find the square root of a number.

The square root of a number is the number which must be squared to obtain number : sqrt(number)^2 is equal to number.

If a math operation on finite inputs produces a non-finite output, an execution error is thrown. See math operation|math operations for more information.

Values:
The sqrt function return|returns a non-negative number.
