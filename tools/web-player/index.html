About the Stack Player

The Stack Player lets anyone try an xTalk stack in a web browser, with nothing to install. It is part of OXT-Beyond, a free and open-source xTalk development environment descended from LiveCode Community.

  • The same engine as the desktopOXT-Beyond's engine is compiled to WebAssembly, so stacks run their own scripts and behave as they do on a computer.
  • Open, play, keepOpen a stack file, a folder or a .zip. It opens in the page, and stays in your library in this browser for next time.
  • Take your changes with you"Download copy" saves the stack as it is now, with any changes it or you made, as a file you can open in OXT-Beyond or LiveCode.

This is a beta. Most modern stacks work, a few things cannot work in any browser, and a few are not done yet. The next pages say which, in plain English.

      What doesn't work

      Some things a browser never lets a web page do. A stack that uses them still opens, and those commands fail as they would on a computer that cannot do them.

        Your files and safety

        Everything happens inside this browser tab.

        • Nothing is uploadedThe stacks you open are copied into this browser's storage for this site, not sent to a server.
        • Your library stays until you remove itYour stacks, and anything they save, are kept for your next visit in this browser. Remove a stack with the bin on its card, or clear this site's data in your browser.
        • A stack is a programA stack runs its own scripts. Here it cannot touch your computer's files, but it can do what any web page can: show things, save into this site's storage, read what other stacks saved here, and make web requests. Open stacks you trust, as you would any program.
