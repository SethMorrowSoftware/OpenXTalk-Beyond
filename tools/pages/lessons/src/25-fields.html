A field is a container

A field holds text the user can read and, unless you lock it, edit. In a script a field works like a variable: you put into it, put after it, read it, and use every chunk expression you know on it.

Styling part of the text

Every text property can be set for a chunk of a field, not just the whole field: a word in bold, a line in another colour, a few characters bigger. A field gives every line the same height unless its fixedLineHeight is false, so turn that off when some lines are bigger than others.

Text with its styles: htmlText

the text of a field is its plain characters. the htmlText is the same text with its styles, in a small dialect of HTML. You can read it to save a field's look, and set it to fill a field with styled text in one go:

To copy text with its styles from one field to another, set the htmlText of field "B" to the htmlText of field "A". A plain put field "A" into field "B" copies only the characters.

Fields as labels

Most text you see in a program that the user cannot change, titles, captions, a score, is a field with its border and background turned off and its text locked:

With lockText true the user cannot type into the field, and a click on it sends mouseUp to it like a button's.

Columns with tabs

A tab character moves the text on to the next tab stop. Set a field's tabStops and lines with tabs between their parts line up as a table. In the script, set the itemDelimiter to tab and each column is an item:

For bigger tables, with columns the user can sort and resize, OXT-Beyond has the Data Grid, which its own guide covers in Help > Guides.

A list to choose from

Set a locked field's listBehavior to true and it becomes a list: a click highlights a whole line. the hilitedLine says which line is chosen (and setting it chooses one), and the selectedText gives its text.

A list field sends mouseUp when a line is clicked, so its script can read the selectedText of me and act on the choice.

Long text: scrolling

A field with more text than fits can have a scroll bar: set its vScrollbar to true. Its scroll property is how far down it is scrolled, in points.

Build long text in a variable and put it into the field once, as here. Putting into a field a line at a time makes it redraw every time, which is much slower when there are thousands of lines.
