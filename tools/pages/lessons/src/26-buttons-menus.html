A button of every kind

A button's style decides what it is. A plain push button is standard; the same object becomes a checkbox, a radio button, a flat transparent hot spot, a rounded button or a menu just by changing its style.

Checkboxes and hilite

A checkbox is on or off, and its hilite says which. Clicking it turns it on and off by itself (its autoHilite is true), and a script can read or set it. Radio buttons

Radio buttons offer a choice of one. Put them in a group and set the group's radioBehavior: choosing one then un-chooses the others, and the group's hilitedButtonName says which is on.

Buttons that are menus

A button with the style menu shows a menu, and its menuMode says which kind: option (a pop-up list that shows the choice), comboBox (a list you can also type into), pulldown, popup and tabbed. The lines of the button's text are the menu's items.

Tabs

A tabbed button draws a row of tabs; picking one sends menuPick, and the script shows the controls that belong to that tab (often a group for each) and hides the others.

Enabled, disabled and default

A button that cannot be used right now should say so: set its enabled to false (or disable it) and it greys out and ignores clicks. The default button of a dialog, the one Return presses, is drawn with a heavier outline on some systems.
