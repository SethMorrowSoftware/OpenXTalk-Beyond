Properties of your own

Besides the properties xTalk gives every object, an object can hold custom properties: any name you choose, any value you like. You set and read them exactly like built-in ones. The usual habit is to start their names with c (or u, for "user"), so they never clash with a property xTalk may add one day.

A custom property nobody has set is simply empty.

Why not a variable?

A variable lasts as long as the program runs. A custom property belongs to its object, so it is saved with the stack: close the stack, open it next week, and the value is still there. That makes custom properties the natural place for:

  • settings and preferences: the cSoundOn of this stack
  • the state of an object: how many times a button was clicked, which page a book was left open at
  • data an object carries: the price of a product card, the answer to a quiz question

Click the button on the stage and it goes on counting: the count lives in the button, not in a variable of the script.

Only a stack that is saved keeps its values. The stage is made anew at every run, so its properties last only until the next one; in your own stacks they last for good.

Properties with keys

A custom property can be read and set a key at a time, which groups related values under one name. The group is called a custom property set, and the customProperties with its name gives the whole set as an array:

Switching sets

An object can have several sets, and its customPropertySet says which one plain the cName reads and writes. One use is translation: a set for each language, with the same names in each, and the stack switches between them.

The other side of the coin

Because any unknown name makes a custom property, a misspelled built-in property quietly creates one instead of failing, as Properties showed. The c at the front of your own names helps here too: a property without it should be one of xTalk's.

And when a property should be worked out each time it is read, rather than stored, a getprop handler can answer for it: the lesson Virtual properties shows how.
