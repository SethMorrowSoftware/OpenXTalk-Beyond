Every object has properties

A property is one fact about an object: its name, its size, its colour, the text on it, whether it can be seen. You read one with the and change one with set:

A button's label is the text it shows; its name is what scripts call it. Keeping them apart lets you change the words on a button, or translate them, without breaking a single script.

Size and place

Several properties describe where a control is, and they all stay in step: change one and the others follow.

  • rect: left, top, right, bottom
  • loc: the point at its centre
  • width and height
  • left, top, right, bottom, and the corners topLeft, bottomRight and so on

Colours

A colour can be a name ("orange", "navy", "darkred"), a web-style hex code ("#5FE0CF") or three numbers from 0 to 255 for red, green and blue. backgroundColor fills a control, textColor colours its text, borderColor its edge.

The first colour is written 255 0 0 in the loop, because the commas would split it into three items; setting it again with commas works, since a property takes the whole value.

Text properties

Fields and buttons share a set of text properties: textFont, textSize, textStyle (plain, bold, italic, underline and more, joined with commas), textColor and textAlign (left, center or right).

Showing and hiding

A control's visible property says whether it shows. hide and show are short ways to set it. A hidden control is still there, with all its properties and its script: it is only out of sight.
