# Android card: a click on the "OXT-Beyond engine (preview)" box (patch
# -1) stores the "android,engine" setting, which the Android builder reads:
# "beyond" when the box is ticked, empty (LiveCode 9.6.3's engine, the
# default) when it is not. The targets group's script takes it first, so it
# is never taken for an architecture (by its second word) or for "App
# Bundle"; the architectures' boxes and "App Bundle" do what they did. The
# text replaced is the script's first lines, which the "App Bundle" patch
# (android-card-app-bundle-2.txt) leaves as they were, so that each patch
# finds its own text whichever ran first.
file: Toolset/palettes/standalone settings/revstandalonesettings.8.rev
object: group "Android Targets" of card "Android"
replace:
|on mouseUp|
|   if word 1 of the target is not "button" then|
with:
|on mouseUp|
|   -- OXT-Beyond: the "OXT-Beyond engine (preview)" box ("Beyond Engine")|
|   -- is no architecture: ticked, the package is built with OXT-Beyond's|
|   -- own Android engine ("android,engine" is beyond), else with LiveCode|
|   -- 9.6.3's (empty, the default)|
|   if word 1 of the target is "button" and the short name of the target is "Beyond Engine" then|
|      if the hilite of the target then|
|         storeSetting "engine", "beyond"|
|      else|
|         storeSetting "engine", empty|
|      end if|
|      exit mouseUp|
|   end if|
|   if word 1 of the target is not "button" then|
